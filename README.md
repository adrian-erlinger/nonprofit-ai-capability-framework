# Nonprofit AI Capability Framework

This repository is the canonical source for the development of the Nonprofit AI Capability Framework: a public framework for helping nonprofits and member-based associations move AI from individual experimentation into sustained organizational practice.

The project is in Phase 0: product foundation and repository design. Its assumptions are early and not yet validated through user interviews, prototype testing, or implementation work.

## Who This Is For

This framework is initially intended for nonprofits and member-based associations within the broader dot org market. It focuses on helping organizations turn useful individual experimentation into repeatable, managed organizational practice.

## Repository Role

This repository records the framework's governing decisions, working hypotheses, research basis, and development plans.

The framework may support a future paid DSL product with a guided digital experience, facilitation, training, or implementation services. The public repository is the foundation for that potential product, not the finished product itself.

## Current Contents

## Current Phase Boundaries

Phase 0 does not include production application code, production UI specifications, authentication, live organizational data, integrations, security controls, or production infrastructure.

Bounded prototypes using synthetic data may be created during Phase 0 to test workflow logic, usability, comprehension, and commercial interest. These prototypes should be treated as learning instruments, not validated products.
