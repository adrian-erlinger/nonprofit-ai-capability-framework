# Nonprofit AI Capability Framework

The Nonprofit AI Capability Framework helps nonprofit and association leaders move from scattered AI experimentation toward responsible organizational practice. It starts with a real organizational concern, identifies the workflow behind it, and helps determine whether AI, prerequisite work, a non-AI intervention, or stopping a proposed intervention is the responsible next move.

Data Strategy Lab maintains this repository as the canonical source for the framework's open methodology, governance, templates, and reference examples.

## What the Framework Does

The framework guides one leader or team through one organizational concern and one bounded workflow at a time. It clarifies the desired outcome, current workflow, root problem, stakeholders, intervention options, AI suitability, adoption requirements, evidence needs, and bounded learning cycle.

The intended output is a responsible next move and a concise Decision Conversation Brief. The four approved AI-suitability conclusions are:

- Proceed with an AI-supported workflow.
- Prepare first, then reconsider AI.
- Pursue a non-AI intervention.
- Do not pursue the proposed intervention.

## Current Version

The current open methodology is Framework v0.1. It includes an eleven-domain reasoning model, a facilitated Decision Conversation protocol, a facilitator worksheet, a client-facing brief template, a beta test plan, and a complete synthetic end-to-end example.

These materials are usable now for facilitated discovery conversations, internal practice, and structured beta testing. They do not claim field validation, commercial validation, or application deployment.

## Who This Is For

The framework is intended for nonprofits and member-based associations within the broader dot org market. It is especially suited to leaders who need to examine a concrete workflow, clarify whether AI is appropriate, and define a responsible next action.

## Repository and Application Roles

This repository contains the open methodology, governance, templates, and reference examples for the Nonprofit AI Capability Framework v0.1. It is the canonical source of truth for how the methodology is defined and revised.

A separate hosted application will provide the guided user interface and AI-assisted delivery layer. The public repository will remain the methodology, governance, templates, and reference-example layer.

## Current Scope

The repository does not currently contain the hosted application, authentication, production integrations, or live organizational data handling.
